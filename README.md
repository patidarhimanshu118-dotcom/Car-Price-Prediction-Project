# Car-Price-Prediction-Project
•	Built a data preprocessing pipeline using Python to handle missing values, encode categorical features, and normalize numerical variables for model training. 
•	Trained and evaluated Support Vector Classifier (SVC) and Random Forest models, achieving 85% classification accuracy in predicting vehicle price categories. 
•	Performed exploratory data analysis (EDA) to identify the impact of ownership history, fuel type, transmission, and vehicle age on selling price. 
•	Used SQL queries to extract, filter, and organize vehicle data from multiple tables for analysis and model preparation.
•	Created an interactive Tableau dashboard to visualize pricing trends, feature relationships, and model-driven business insights for stakeholders.
